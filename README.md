# Surr

A browser extension that strips YouTube down to search and Instagram down to friends, messages and search.

## Usage

**Chrome / Brave**

1. Open `chrome://extensions` (or `brave://extensions`) and enable **Developer mode**.
2. Click **Load unpacked** and select the `extension` folder.

**Safari (iOS)**

Install the [Userscripts](https://github.com/quoid/userscripts) app and add `extension/youtube.user.js` and `extension/instagram.user.js` to its scripts folder.

What exactly gets hidden is documented in [`data/specification`](data/specification).
